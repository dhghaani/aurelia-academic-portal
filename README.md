# Aurelia — سامانه مدیریت و تحویل پروژه‌های دانشگاهی

سامانه تحت وب (RTL / فارسی) با طراحی مینیمال برای مدیریت، آپلود، ورژن‌بندی و ارزیابی پروژه‌های دانشگاهی ویژه اساتید و دانشجویان.

## امکانات کلیدی

- **احراز هویت مجزا برای استاد و دانشجو:**
  - حساب پیش‌فرض استاد: نام کاربری `admin` | رمز عبور `123`
  - حساب پیش‌فرض دانشجو: نام کاربری `stu` | رمز عبور `321`
- **مدیریت حساب کاربری:** امکان ویرایش نام و نام خانوادگی (نمایش در هدر سایت)، نام کاربری و رمز عبور برای هر دو نقش.
- **پنل استاد:**
  - مشاهده لیست پروژه‌های آپلود شده دانشجویان (شامل نام پروژه، نام دانشجو، نام کلاس، ورژن و وضعیت ارزیابی)
  - مشاهده جزئیات هر پروژه، ثبت نمره (از ۲۰) و تغییر وضعیت (تایید نهایی / نیاز به اصلاح / در انتظار بررسی)
  - ارسال اعلان مستقیم برای دانشجو روی هر پروژه
- **پنل دانشجو:**
  - مشاهده لیست پروژه‌های آپلود شده و بررسی نمره، نظر استاد و اعلانات
  - آپلود پروژه جدید (نام و نام خانوادگی، نام استاد، نام پروژه، ورژن، نام کلاس، فایل و توضیحات)
  - ثبت ورژن جدید (Semantic Versioning) همراه با تاریخچه نسخه‌ها
- **پشتیبانی از دو تم:** حالت تاریک لوکس (Obsidian & Gold) و حالت روشن استاندارد (Editorial Ivory).

## نحوه اجرا
