# AURELIA Academe — سامانه مینیمال و لوکس مدیریت پروژه‌های دانشگاهی

سامانه تحت وب (RTL / فارسی) با طراحی مینیمال و لوکس برای مدیریت، آپلود، ورژن‌بندی و ارزیابی پروژه‌های دانشگاهی ویژه اساتید و دانشجویان.

## امکانات کلیدی

- **صفحه لندینگ مینیمال و استاندارد** همراه با معرفی چرخه ۴ مرحله‌ای تحویل تا ارزیابی
- **۳ پنل استاد کاملاً ایزوله + ۱ پنل دانشجو:** هر پروژه‌ای که دانشجو برای درس یک استاد آپلود کند، تنها در پنل، آمار، تاریخچه و اعلانات همان استاد نمایش داده می‌شود.
- **لیست کشویی دروس با تشخیص خودکار استاد:** هنگام آپلود پروژه جدید، با انتخاب درس از لیست کشویی، نام استاد مربوطه به‌صورت خودکار زیر همان فیلد نمایش داده و ثبت می‌شود.
- **مدیریت حساب کاربری:** امکان ویرایش نام و نام خانوادگی (نمایش زنده در هدر سایت)، نام کاربری و رمز عبور برای هر حساب.
- **ارزیابی، ورژن‌بندی و کارنامه قابل چاپ:** ثبت نمره (از ۲۰)، وضعیت تایید/اصلاح، تاریخچه نسخه‌ها و خروجی چاپی/دانلودی کارنامه رسمی.
- **تم تاریک لوکس و تم روشن استاندارد** + ذخیره‌سازی دائمی در `localStorage`.
